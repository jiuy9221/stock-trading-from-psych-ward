# 云端自动任务配置说明

## 一、任务概述
本任务实现小说第二版的自动创作，每10分钟执行一次，每次生成10章内容。

## 二、任务配置

### 2.1 在Trae SOLO中创建自动化任务

**方法一：对话模式创建（推荐）**

在Trae SOLO对话中输入：
```
帮我创建一个云端自动化任务，具体要求：
1. 任务名称：小说自动创作
2. 触发时间：每10分钟执行一次
3. 执行方式：云端任务（MTC模式）
4. 任务内容：
   - 进入目录 d:\GitHub\2026\其他\精神病院炒股事件合集\v2
   - 运行 python auto_write_novel.py
5. 任务类型：云端任务
```

**方法二：手动创建**

1. 打开Trae SOLO，进入"自动化任务"页面
2. 点击"新建任务"
3. 填写任务信息：
   - 任务名称：小说自动创作
   - 触发类型：定时触发
   - 触发时间：每10分钟
   - 任务模式：MTC模式
   - 任务内容：
     ```
     cd d:\GitHub\2026\其他\精神病院炒股事件合集\v2
     python auto_write_novel.py
     ```
   - 运行方式：云端任务

### 2.2 任务执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                    定时任务触发（每10分钟）                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  1. 读取开发计划文档，获取当前完成章节数                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 判断是否已完成全部500章                                    │
│     - 是：输出完成提示，结束任务                               │
│     - 否：继续下一步                                          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 生成下一批10章内容（每章2000-3500字）                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 将新章节追加到小说文件                                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  5. 更新开发计划文档（进度、状态）                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  6. 提交更改到Gitee                                          │
└─────────────────────────────────────────────────────────────┘
```

## 三、文件说明

## 四、配置要点

### 4.1 Git配置（首次运行前）

确保已配置Git远程仓库：
```bash
cd d:\GitHub\2026\其他\精神病院炒股事件合集
git remote add origin https://gitee.com/your_username/your_repo.git
git config user.email "your_email@example.com"
git config user.name "Your Name"
```

### 4.2 运行环境要求

- Python 3.6+
- Git（已配置Gitee远程仓库）
- 网络连接（用于Git推送）

## 五、注意事项

1. **执行频率**：建议从每小时执行一次开始测试，确认稳定后再调整为10分钟
2. **资源占用**：云端任务会占用一定的计算资源，注意监控
3. **网络依赖**：需要网络连接才能提交到Gitee
4. **完成检测**：脚本会自动检测是否已完成500章，完成后自动停止
5. **错误处理**：如果Git提交失败，脚本会继续运行，但会输出错误信息

在创建定时任务前，建议先手动测试一次：

```bash

python auto_write_novel.py
```

确认脚本能正常运行后，再设置定时任务。
